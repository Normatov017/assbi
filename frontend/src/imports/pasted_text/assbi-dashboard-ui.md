Create a modern, professional, Power BI–style dashboard UI design for an AI-Driven Business Intelligence Platform for Smart Surveillance and Human Activity Analytics.

Project name: ASSBI Platform – AI Smart Surveillance & Business Intelligence Dashboard.

The system is used by universities, smart campuses, public streets, transport hubs, municipal authorities, and private security organizations to monitor human movement, crowd density, security risks, operational efficiency, and AI-based anomalies in real time.

Design style:
- Premium enterprise SaaS dashboard
- Similar visual quality to Microsoft Power BI, Datadog, Grafana, and modern AI analytics platforms
- Dark mode main theme with optional light mode version
- Clean layout, glassmorphism cards, soft shadows, rounded corners, professional spacing
- Use a futuristic but serious smart-city surveillance style
- Main colors: dark navy, electric blue, cyan, purple accent, green for safe, orange for warning, red for critical alerts
- Use clear data visualization, KPI cards, maps, AI analytics panels, video monitoring sections, and report widgets

Important UI details:
- Use realistic dashboard data
- Use strong hierarchy: big KPIs, clear charts, clean tables
- Make it look suitable for a university assignment but professional enough for a real enterprise product
- Use Uzbek or English labels consistently; English preferred for professional dashboard
- Add small details like “Live”, “AI Confidence 94%”, “Updated 5 sec ago”, “Critical Alert”, “Export Report”
- Design should be responsive for desktop dashboard first, then tablet/mobile versions
- Create components for buttons, cards, sidebar, charts, tables, badges, modals, and camera feed cards
- Use modern icons for camera, users, alert, map, analytics, AI, database, report, settings
